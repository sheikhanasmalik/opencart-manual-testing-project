# OpenCart Manual Testing Project

## Project Overview
This project demonstrates end-to-end manual testing of the OpenCart E-Commerce application.

## Modules Tested
- User Registration
- Login
- Product Search
- Product Details
- Add to Cart
- Wishlist
- Checkout
- Order Confirmation
- Logout

## Deliverables
- Functional Requirement Specification (FRS)
- Test Plan
- Test Cases
- Bug Reports
- Requirement Traceability Matrix (RTM)
- Test Execution Report

## Testing Types
- Functional Testing
- Positive Testing
- Negative Testing
- Regression Testing
- UI Testing

## Tools Used
- Microsoft Excel
- Microsoft Word
- GitHub
